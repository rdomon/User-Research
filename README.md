# BODiFi Music Player — Live Spotify / Raspberry Pi variant

This is the **online, live Spotify version**, with a 1024 × 600 touchscreen layout.
It requires internet, a Spotify Premium account, authorization, and a compatible browser. This is not an offline deliverable for Milestone 1.

## Main flow
Select instructor → Choose Spotify → Sign in (first time) → Continue to Class type → Choose a class → Choose one of your Spotify playlists → Now Playing.
The Search Spotify overlay also offers Search, My Library, Account. Controls include play/pause, previous/next, shuffle, seeking, and volume.

## Tests
